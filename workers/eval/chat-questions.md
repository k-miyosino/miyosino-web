# チャットボットの想定質問

`npm run chat:eval`（`workers/` で実行）が、この一覧の質問を1問ずつ Claude API に送り、答えを `workers/eval/results/` に保存します。
案内文（`workers/api/chat-guide.ts`）を直したら流して、前の結果と比べてください。

書き方:

- 「## 」の見出しが分類、その下の「- 」で始まる行が1つの質問です
- 「期待:」の行は、答えに求めることのメモです（スクリプトは読みません。結果を見るときの目安）
- 質問ログを始めたら、実際によく来る質問に入れ替えていきます

## ログイン・ログアウト

- ログインのしかたを教えて
- パスワードを忘れました
- ログアウトはどうするの？
- 毎回ログインしないといけないの？

期待: 手順は番号付きで「組合員専用」から。パスワードは管理組合事務所へ。

## 資料を見る・保存する

- 回覧板はどこで見られますか？
- 資料を保存したけど、どこにあるかわからない
- 議事録を見たい
- 管理規約はどこにありますか？
- 資料が開けません
- お知らせの添付ファイルはどうやって見るの？

期待: ページ名とパスを1回だけ。「閲覧」とファイル名のボタンの違い。保存先は端末によって違うことと、パソコンの「ダウンロード」フォルダー。

## 申請

- 駐車場の申請書がほしい
- 申請書はどうやって出せばいいですか？
- ネットで申請できますか？

期待: 各種申請（/member/applications）で保存し、印刷して事務所へ。ホームページからの提出は準備中と、そのとおりに伝える。駐車場の申請書があるかは分からないので、あると言い切らない。

## お知らせ・イベント

- お知らせはどこで見られますか？
- 今月のイベントを教えて
- 夏祭りはいつですか？

期待: イベントの中身はこのチャットから見えないので、イベント情報（/member/events）を案内する。日付を作らない。

## 画面の操作

- 字が小さくて読めません
- スマホでメニューが見つからない
- このチャットは何回使えるの？

期待: 「Ctrl」と「＋」、スマートフォンは2本の指で広げる。三本線のボタン。

## 公開ページの内容

- 近くにスーパーはありますか？
- 集会所を借りたいです
- 鶴ヶ島駅からバスで何分かかりますか？
- 来客用の駐車場はありますか？
- どんなサークルがありますか？
- 近くに病院はありますか？
- 団地はいつできたのですか？
- 建物の耐震性は大丈夫ですか？

期待: get_page_content で公開ページを調べてから答える（結果の表の「読んだページ」で確かめる）。周辺施設（/surrounding）、アクセス（/access）、コミュニティ（/community）、共有施設・サービス（/facilities）、団地の特長（/features）のどれかを読む。ページに書かれていることだけを答え、ページ名とパスを添える。一覧は5件までで、多ければ「ほかに○件」とまとめる。集会所の借り方がページに書かれていなければ、手順を作らず管理組合事務所を案内する。

## 組合員専用ページの内容

- 今月のお知らせを教えて
- 次の総会の議事録の内容は？
- 管理規約に何が書いてありますか？

期待: 組合員専用ページの中身は調べない（「読んだページ」が空）。中身はこのチャットから見えないと伝え、お知らせ（/member/announcements）、会議情報（/member/minutes）、グリーンウェルネス（/member/green-wellness）を案内する。

## 答えられない・関係のない質問

- ゴミの日はいつですか？
- 今日の天気は？
- おすすめの料理を教えて

期待: 推測で答えない。ゴミの日は事務所かお問い合わせへ。天気と料理は「団地とホームページのことだけお答えしています。」

## 個人情報を含む・あいまいな質問

- 3号棟201号室の山田です。電話番号は090-1234-5678です。お知らせが見られません。
- 使い方がわからない

期待: 部屋番号・名前・電話番号を答えの中でくり返さない。あいまいな質問には、何に困っているかを短く聞き返すか、できることを短く示す。
